從 NovelAI 帳號設定取得 Persistent API Token。AES-GCM 加密資料隨目前 ST 使用者設定保存，解鎖密語不保存；重整後需重新解鎖。也可只放在目前分頁記憶體，不留下 Token 設定。加密需 HTTPS 或 localhost；不讀取／覆蓋 ST 主連線或舊版 secrets，舊版使用者需重新貼上一次。請只安裝可信擴展，解鎖中的 Token 必須供瀏覽器使用。
插件限制：寬高為 64 的倍數、每張最多 3145728 像素、每次總計最多 4194304 像素。不自動添加品質或負向標籤。實際模型權限、可用參數與扣點依 NovelAI 帳號為準。

提示詞生成（獨立 LLM 連線）
尚無設定檔？到「API 連線」→「連線設定檔」建立一個（支援 Chat Completion 與 Text Completion）。
端點會接在 Base URL 後方，例如 https://api.openai.com/v1 + chat/completions。非本機網址必須使用 HTTPS；請確認服務允許瀏覽器 CORS 與 Authorization／自訂 Header 預檢。遠端 HTTPS ST 直連本機 HTTP LLM 仍可能被瀏覽器的 Mixed Content／Private Network Access 政策阻擋。
API Key 會依你的選擇以明文保存在目前 SillyTavern 使用者的擴充設定中，並可能出現在設定匯出或備份。請勿分享設定檔，只在可信的 ST 網站與擴充中使用。測試會送出一個極短的 Chat Completions 請求，可能產生少量費用。
匯入 ST Chat Completion 預設（prompts / prompt_order），或舊版 main_prompt / nsfw_prompt / jailbreak_prompt。只存入本插件，不切換或覆蓋 ST 主預設。API 網址、金鑰、Headers 與模型仍由上方連線決定。 提示詞本身或所選順序任一處 enabled:false 都保持關閉；順序未明確啟用的條目也不送出。按角色、相對順序與 In-Chat 深度組裝訊息，生成類型為 quiet。Chat History 放入所選前文與目標樓層，不讀取之後的樓層；未列出此 marker 時自動放入場景，明確停用則不放入（可改用 \{{message}}）。此模式不附加下方舊 System / User 模板。 原生 extensions.regex_scripts 只在此預設內依開關、深度和用途處理；不讀取主聊天／全域正則，不混用 SPreset。預設巨集變數在每次生圖對話中獨立。互動 HTML 先以靜態預覽顯示，JS 需於面板內明確啟用；送出仍需插件按鈕確認，生圖另行確認。 不執行世界書掃描、酒館助手腳本、STscript、工具或完整聊天生成流程。HTML 腳本只支援有限的獨立輸入框／送出相容介面，不提供主聊天 API；未支援巨集保留為文字並警告。舊版匯入未保存正則，請重新匯入原始 JSON。
