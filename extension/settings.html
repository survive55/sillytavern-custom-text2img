SillyTavern Custom Text2Img
純網頁版：NovelAI 由瀏覽器直連官方 API；ComfyUI／Modal 直連已更新的控制面板。兩者皆不需要 ST 後端插件、npm 安裝或修改 ST 設定。 兩個來源的圖片參數各自保存；共用下方獨立的提示詞連線設定檔，不更動主聊天設定。
圖片伺服器（ComfyUI on Modal 控制面板）
填控制面板的 HTTPS／Quick Tunnel 網址；只有瀏覽器與面板同機時才可填 http://127.0.0.1:8800。瀏覽器以短效 Token 登入及輪詢，不依賴跨站 Cookie 或 SSE。面板需提供 /api/browser；不要填 ST 網址或 Modal 原生 ComfyUI 網址。
測試連線
預設組合提供 panel_values / group_states / LoRA / 解析度 / 批次數；下方圖片參數若有填值會覆蓋它。
NovelAI 官方圖片 API 固定使用 https://image.novelai.net/ai/generate-image，不需要 ComfyUI、Modal 網址或密碼。
從 NovelAI 帳號設定取得 Persistent API Token。AES-GCM 加密資料隨目前 ST 使用者設定保存，解鎖密語不保存；重整後需重新解鎖。也可只放在目前分頁記憶體，不留下 Token 設定。加密需 HTTPS 或 localhost；不讀取／覆蓋 ST 主連線或舊版 secrets，舊版使用者需重新貼上一次。請只安裝可信擴展，解鎖中的 Token 必須供瀏覽器使用。
插件限制：寬高為 64 的倍數、每張最多 3145728 像素、每次總計最多 4194304 像素。不自動添加品質或負向標籤。實際模型權限、可用參數與扣點依 NovelAI 帳號為準。
生圖可能消耗 Anlas，批次數大於 1 亦可能收費。僅在你點擊樓層按鈕時送出，失敗不自動重送；停止等待或鎖定 Token 不代表取消扣點。結果只在目前分頁暫存 30 分鐘；關閉／重整頁面可能遺失尚未保存的圖片，請等候存入聊天後再離開。
提示詞生成（獨立連線設定檔）
尚無設定檔？到「API 連線」→「連線設定檔」建立一個（支援 Chat Completion 與 Text Completion）。 可用巨集：\{{message}} 目標楼層、\{{history}} 前文、\{{description}} 角色描述、\{{char}}、\{{user}} 及其他 SillyTavern 巨集。
