提示詞生成（獨立 LLM 連線）
尚無設定檔？到「API 連線」→「連線設定檔」建立一個（支援 Chat Completion 與 Text Completion）。
端點會接在 Base URL 後方，例如 https://api.openai.com/v1 + chat/completions。非本機網址必須使用 HTTPS；請確認服務允許瀏覽器 CORS 與 Authorization／自訂 Header 預檢。遠端 HTTPS ST 直連本機 HTTP LLM 仍可能被瀏覽器的 Mixed Content／Private Network Access 政策阻擋。
API Key 會依你的選擇以明文保存在目前 SillyTavern 使用者的擴充設定中，並可能出現在設定匯出或備份。請勿分享設定檔，只在可信的 ST 網站與擴充中使用。測試會送出一個極短的 Chat Completions 請求，可能產生少量費用。
匯入 ST Chat Completion 預設（prompts / prompt_order），或舊版 main_prompt / nsfw_prompt / jailbreak_prompt。只存入本插件，不切換或覆蓋 ST 主預設。API 網址、金鑰、Headers 與模型仍由上方連線決定。 與原生 ST 一致：以所選 prompt_order 的 enabled 開關為準，再套用 trigger；prompts 內的 enabled 不參與啟用判定。順序未明確啟用的條目不送出。匯入預設 prompts 中 role 為 user 的一般提示詞項目略過（chatHistory／dialogueExamples 容器除外，其內部訊息保留實際角色），不展開巨集、不送給 LLM（含 In-Chat）；獨立面板手動輸入與角色對話範例不受此篩選影響。其餘按角色、相對順序與 In-Chat 深度組裝訊息，生成類型為 quiet。Chat History 放入所選前文與目標樓層，不讀取之後的樓層；未列出此 marker 時自動放入場景，明確停用則不放入（可改用 \{{message}}）。此模式不附加下方舊 System / User 模板。 正文標籤模式只使用 JSON 場景規劃，不開啟舊版獨立提示詞／HTML 互動面板。原生 extensions.regex_scripts 仍依開關、深度和用途處理；不讀取主聊天／全域正則，不混用 SPreset。預設巨集變數在本次分析中獨立。 不執行世界書掃描、酒館助手腳本、STscript、主聊天工具或完整聊天生成流程；Anima MCP 工具需在其獨立區塊明確開啟；未支援巨集保留為文字並警告。舊版匯入未保存正則，請重新匯入原始 JSON。
